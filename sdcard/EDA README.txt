1. ОБЗОР ПРИЛОЖЕНИЯ
================================================================================

Enhanced Drone Analyzer (EDA) — приложение для обнаружения и анализа
беспилотных летательных аппаратов (БПЛА) на базе HackRF One с прошивкой
PortaPack Mayhem.

Основные возможности:
  - Сканирование радиочастотного спектра от 1 МГц до 7,2 ГГц
  - Режим развёртки (SWEEP) — до 300 МГц за цикл
  - Отслеживание дронов в реальном времени с классификацией угроз
  - 7 алгоритмов CFAR-детектирования
  - Фильтр Махаланобиса для отсеивания статистических выбросов
  - Анализ формы спектра (V-образная форма, глубина впадины, симметрия)
  - Автоматическое управление усилением радиотракта (AGC)
  - Звуковые оповещения с SOS-последовательностью для критических угроз
  - Сохранение настроек на SD-карту

Целевая платформа:
  - МК: STM32F405RG (ARM Cortex-M4F, 168 МГц)
  - ОЗУ: 128 КБ SRAM (~64 КБ доступно для приложения)
  - Flash: 1 МБ
  - ОС: ChibiOS (кооперативные + превентивные потоки)
  - Дисплей: 240×320 пикселей, 16 бит RGB565
  - RF: HackRF One (Si5351, MAX2837, RFFC5072)

2. ЗАПУСК И ОСНОВНОЙ ЭКРАН
================================================================================

Запуск:
  1. Включите PortaPack (кнопка питания на корпусе)
  2. В главном меню Mayhem выберите "EDA" (Enhanced Drone Analyzer)
  3. Дождитесь инициализации радиотракта (1-2 секунды)

При первом запуске приложение загружает базу данных частот из файла
/FREQMAN/DRONES.TXT. Если файл отсутствует — отобразится предупреждение,
но приложение продолжит работу в режиме широкополосного сканирования.

Элементы интерфейса:
  LNA      — Усиление малошумящего усилителя (0-40 дБ, шаг 8 дБ)

  Частота  — Текущая настроенная частота в МГц

3. РЕЖИМЫ РАБОТЫ
================================================================================

3.1 Последовательное сканирование (Sequential / база данных)
-------------------------------------------------------------
Как включить: Нажмите [DB] (Database). Повторное нажатие [DB] останавливает
DB-сканирование. Из режима SWEEP кнопка [DB] выходит и продолжает DB-скан
с сохранённой частоты.

Приложение последовательно перебирает частоты из загруженной базы данных.
На каждой частоте:
  - Анализирует спектр ±10 МГц полосы (20 МГц захват, бин 78.125 кГц —
    тот же размер бина, что и в SWEEP; весь FPV-канал ~18 МГц виден целиком)
  - Измеряет RSSI (уровень сигнала)
  - При обнаружении сигнала выше порога — создаёт запись в списке угроз

ВАЖНО (калибровка): из-за широкого бина абсолютные уровни выше примерно
на 10 дБ, чем при старом захвате 2 МГц. Порог RSSI (Sens) и пороги
угроз (Lo/Md/Hi/Cr) нужно один раз подстроить под новое окно.

Индикация:
  Серый    — сканирование, нет сигнала
  Жёлтый   — обнаружен сигнал, анализ (LOCKING)
  Зелёный  — отслеживание обнаруженного дрона (TRACKING)
  Красный  — критический уровень сигнала (CRITICAL)

Звуковые сигналы:
  Одиночный звук (1000 Гц) — новый дрон обнаружен
  SOS (1200 Гц) — высокая угроза / приближение
  SOS (1500 Гц) — критическая угроза

3.2 Режим развёртки (SWEEP / Looking Glass)
---------------------------------------------
Как включить: Нажмите [Start] — из покоя кнопка [Start] ВСЕГДА запускает
развёртку. Повторное нажатие [Start] возобновляет развёртку после [Stop];
[Stop] приостанавливает показ, [Start] возвращает его.

Режим быстро «развёртывает» любой диапазон частот от 1 до 7200 МГц,
отображая спектр в реальном времени. Работает как анализатор спектра с
водопадным отображением.

Окна развёртки по умолчанию (редактируются в [SWP], см. раздел 9):
  Окно 1: 5645-5945 МГц  — Основной FPV-диапазон 5.8 ГГц (всегда активно)
  Окно 2: 2400-2500 МГц  — Wi-Fi дроны, управление 2.4 ГГц (по умолч. ВЫКЛ)
  Окно 3: 900-1000 МГц   — Диапазон 900 МГц (по умолч. ВЫКЛ)
  Окно 4: 1200-1300 МГц  — 1.2 ГГц дальнобойные FPV (по умолч. ВЫКЛ)

Важно: Можно включить одно или несколько окон одновременно. Приложение
циклически переключается между активными окнами.

Окна детекции (Det.Win): В каждом окне можно задать до 5 диапазонов
«от/до» (МГц), внутри которых работает детекция. Если все 5 диапазонов = 0
(по умолчанию) — детекция по всему диапазону окна развёртки. Если включён
хотя бы один — игнорируются все обнаружения вне включённых диапазонов.
Спектр окна при этом всегда рисуется полностью (вырезание по радиусу удалено).

3.3 Автоматический режим (Auto-SWEEP)
---------------------------------------
Как работает: В режиме базы данных приложение автоматически переключается
в SWEEP каждые 200 сканов базы данных (DB_SCANS_PER_SWEEP). После
завершения цикла развёртки возвращается к сканированию базы.

Это позволяет не пропустить дроны на неизвестных частотах, сохраняя
при этом детальное сканирование известных каналов.

================================================================================
4. УПРАВЛЕНИЕ СКАНИРОВАНИЕМ
================================================================================

[Start] / [Stop]
  [Start] из покоя ВСЕГДА запускает развёртку (SWEEP). Повторное [Start]
  возобновляет показ после [Stop]; [Stop] останавливает активный режим
  (SWEEP или DB).

[DB]
  Сканирование по базе данных (бывшая кнопка [Mode]):
  - DB-сканирование идёт → нажатие [DB] останавливает его
  - Остановлено → нажатие [DB] запускает DB-сканирование с текущей частоты
  - Идёт SWEEP → нажатие [DB] выходит из развёртки и продолжает DB-скан
    с сохранённой частоты

[Load]
  Загрузка другой базы данных частот:
  1. Нажмите [Load]
  2. Выберите файл .TXT из папки /FREQMAN/
  3. Приложение перезагрузит базу и продолжит сканирование

  Формат файла базы данных:
    f=5645000000,d=FPV Raceband CH1
    f=5658000000,d=DJI O3
    f=2400000000,d=WiFi Drone Control

  Первая часть описания (до пробела) определяет тип дрона:
    FPV, DJI, PARROT, YUNEEC, HOBBY, AUTEL, 3DR, CUSTOM, OTHER

[Set] — Настройки обнаружения
  Открывает экран настроек детекции (см. раздел 5).

[SWP] — Настройки развёртки
  Открывает настройки окон развёртки (см. раздел 9).

5.2 Пояснения к основным параметрам
-------------------------------------

Int (ms) — Интервал сканирования
  Определяет, как часто приложение переключает частоту и анализирует
  спектр. Меньшие значения = быстрее сканирование, но менее стабильные
  измерения. Рекомендуется: 50 мс (20 частот/сек).

Sens — Порог чувствительности
  Управляет порогом обнаружения сигнала. Значение 0 = -20 дБм (очень
  строгий), 100 = -120 дБм (максимально чувствительный); порог = -20 - Sens.
  По умолчанию 85 (-105 дБм). После калибровки (см. 3.1) подстраивайте
  под реальные уровни.

Low/Med/High/Crit — Пороги угроз
  Определяют границы между уровнями угроз:
    LOW:    -95 дБм (слабый, но обнаруженный сигнал)
    MEDIUM: -89 дБм (умеренный сигнал)
    HIGH:   -85 дБм (сильный сигнал)
    CRITICAL: -82 дБм (очень сильный, близкое расстояние)

  Важно: MEDIUM должен быть как минимум на 3 дБ выше порога обнаружения
  (Low), иначе полоса LOW будет недостижима.

Dwell — Задержка на частоте
  При включении приложение задерживается на каждой частоте на несколько
  циклов для подтверждения наличия сигнала. Уменьшает ложные срабатывания,
  но замедляет сканирование.

Conf N — Количество подтверждений
  Сколько раз подряд необходимо обнаружить сигнал, чтобы создать запись
  о дроне. Больше = меньше ложных, но медленнее обнаружение.

Miss T — Пропусков до потери захвата
  Сколько циклов подряд можно пропустить сигнал, прежде чем запись о
  дроне будет удалена. Увеличивайте для нестабильных аналоговых FPV-сигналов.

Neighbor — Маргин соседних бинов
  Центральный бин сигнала должен превышать соседние бины на это значение.
  0 = отключено, 2 = рекомендуется для FPV (широкий сигнал), 5 = строго.

RSSI Var — Фильтр дисперсии RSSI
  Отсеивает шумовые сигналы с хаотическими колебаниями уровня.
  Реальные дроны: дисперсия < 25. Шум: > 100.

Noise BL — Чёрный список шумовых частот
  Если сканер обнаруживает шум на частоте 3+ раза без повышения угрозы,
  частота временно пропускается.

Spectr Det — Детектирование по спектру
  Использует анализ формы спектра для определения наличия сигнала.
  Отключите, если нужно только измерение RSSI.

Md+ — Медианный фильтр
  Подавляет импульсные помехи (микроволновка, Bluetooth). Полезен в
  городских условиях, но может замедлить обнаружение коротких импульсов.

Shape score (Sensitive) — Адаптивный режим Shape (self-tuning)
  НЕ отключает фильтры формы: цепочка работает всегда, но гейт и пороги
  шагов подстраиваются под измеренный шум и SNR сигнала — слабые/дальние
  сигналы проходят мягче, сильные получают пороги в точности как задано.
  ВАЖНО: MinW и MaxW — жёсткие границы пользователя (см. раздел 6):
  в режиме Sensitive они НЕ смягчаются, смягчаются только пороги
  остальных шагов цепочки.
  Открытый гейт может увеличить количество ложных срабатываний — держите
  CFAR/neighbor включёнными.

Bypass — Обход фильтров формы
  При включении пропускает проверку глубины впадины, симметрии и
  эксцесса для очень сильных сигналов (>80 единиц над шумом); при >96
  дополнительно пропускается проверка MaxW.
  По умолчанию ВЫКЛ — фильтры формы работают всегда.

Freq Match — Радиус совпадения частот
  Определяет, насколько близкие по частоте сигналы считаются одним
  дроном. 10 МГц = по умолчанию для аналогового FPV (канал ~18 МГц,
  дрейф гетеродина и FHSS-блуждание легко превышают 1 МГц и плодят
  дубли трекера, дробящие историю RSSI и тренд).
  0 = только точные совпадения (нет слияния).

================================================================================
6. НАСТРОЙКИ ФОРМЫ СПЕКТРА
================================================================================

Фильтры формы спектра определяют характерный «отпечаток» сигнала дрона
(V-образная форма) и отсеивают помехи (WiFi, Bluetooth, микроволновки).

  Параметр         Диапазон    По умолч.  Описание
  ─────────────────────────────────────────────────────────────────────
  Margin (Mar)     5-200       20         Маргина шума (20 = ~4 дБ)
  Min Width (MinW) 1-100       2          Мин. ширина сигнала (бины)
  Max Width (MaxW) 2-255       255        Макс. ширина сигнала (бины)
  Sharpness (Shrp) 50-250      100        Острота пика (отношение пик/среднее)
  Peak Ratio (Rat) 0-255       0          Отношение пик/ширина (0=отключено) хз как это работает. Потом разберусь.
  Valley Depth(Vly) 0-200      0          Глубина впадины (0=отключено)
  Flatness (Flat)  0-100       0          Плосковершинность (% бинов >90% пика)
  Symmetry (Sym)   0-100       0          Симметрия (0=отключено)
  RbF              ON/OFF      ON         Robust width-anchor floor (защита ширины от шума)
  Env              ON/OFF      ON         Пространственный envelope (исправление «ступенек»)

ВАЖНО (MinW/MaxW = границы пользователя): MinW и MaxW работают точно,
как задано — режим Sensitive их НЕ смягчает (смягчаются только пороги
остальных шагов цепочки). Это жёсткие границы вашей полосы: узкие
дроны (ELRS/FrSky 2-8 бинов) проходят при MinW=2, а широкие (WiFi ~256
бинов) отсекаются MaxW (при значении ≥114 предел DC-gap ~114 бинов,
поэтому любые значения ≥114 идентичны). Единственное исключение —
опциональный Byp (по умолчанию ВЫКЛ): при >96 ед. он пропускает MaxW
(см. раздел 5.2); MinW обход не предусмотрен никогда.

Пояснения:

При выборе количества и ширины окон SWEEP учитывайте то что количество отслеживаемых TRACKED сигналов равно 25
Если перегружать устройство лишними записями они будут постоянно заменять друг друга. Для того чтобы сократить количество близких по частоте записей есть параметр MRG он проводит слияние по радиусу. Значение в MHz 10 по умолчанию. То есть 10 слева 10 справа.

Margin — Маргина шума
  Минимальное превышение пика над уровнем шума. 5 единиц ≈ 1 дБ.
  Увеличивайте для строгой фильтрации, уменьшайте для обнаружения
  слабых сигналов.

Min Width (MinW) — Минимальная ширина
  Сигналы уже этого порога отбрасываются как игольчатые всплески.
  2 бина ≈ 156 кГц (по умолчанию) — проходят и узкие ELRS/FrSky
  (2-8 бинов); отсекает одно/двух-биновые шумовые выбросы.
  Поднимайте, если нужно отсечь узкий фоновый шум.

Max Width (MaxW) — Максимальная ширина
  Сигналы шире этого порога отбрасываются как плосковершинный шум.
  255 = без потолка (по умолчанию) — в raw-FFT цепочке ширина ограничена
  DC-gap'ом на ~114 бинах, поэтому любые значения ≥114 идентичны.
  Для жёсткого отсечения WiFi 20 МГц OFDM (~256 бинов) поставьте ~40-60.
  WiFi также отсекают Flat/Sharp/Step 6c (правило ОБА края).
  (WIFI тоже выглядит как расческа — можно поиграть с настройками CFAR,
  но и к дронам чувствительность станет ниже.)

Sharpness (Shrp) — Острота пика
  Отношение маргина пика к среднему маргину. V-образные пики >200,
  плоские WiFi/BT ≈100. 100 = по умолчанию (аналоговое FM-видео даёт
  100-130, WiFi плоская вершина ≈100-110); на WiFi-плотных площадках
  поднять до 140-160; плоские формы отсекаются.

Peak Ratio — Отношение пик/ширина
  Пик делится на ширину сигнала. 0 = отключено (рекомендуется для FPV,
  так как широкий FPV-сигнал имеет низкое соотношение).

Valley Depth (Vly) — Глубина впадины
  Измеряет маргин бинов, примыкающих к пику. V-образный сигнал имеет
  глубокие впадины, WiFi/BT — мелкие. 0 = отключено (по умолчанию —
  старый рекомендуемый порог 80/90 был недостижим на практике); при
  включении включает O(width) скан гребня на каждый пик.

Flatness (Flat) — Плосковершинность
  Процент бинов с мощностью >90% от пика. WiFi/BT: 50-80%,
  drone V-shape: 5-20%. 0 = отключено (по умолчанию для аналогового
  FPV — измерение ненадёжно на аналоговом FM; плоский шум отсекается
  sharpness=100 и широким MaxW/Step 6c). Включается вручную, напр. 45;
  меньше = жёстче.

Symmetry (Sym) — Симметрия
  Отношение меньшей ширины к большей (в процентах). 0 = отключено
  (рекомендуется, так как аналоговый FPV часто имеет легкую
  асимметрию из-за дрейфа модулятора).

Важно: При очень сильных сигналах (>80 единиц над шумом) проверки
глубины впадины, симметрии и эксцесса пропускаются ТОЛЬКО при включённом
Byp (см. раздел 5; по умолчанию ВЫКЛ), так как на близком расстоянии
все бины в полосе сигнала оказываются повышенными. При >96 при включённом
Byp дополнительно пропускается MaxW. MinW при этом всегда остаётся
жёстким (обход MinW не предусмотрен ни при каких настройках).

7. НАСТРОЙКИ CFAR-ДЕТЕКТИРОВАНИЯ
================================================================================

CFAR (Constant False Alarm Rate) — адаптивный порог, подстраивающийся
под уровень шума. Уменьшает ложные срабатывания в различных условиях.

  Параметр         Диапазон    По умолч.  Описание
  ─────────────────────────────────────────────────────────────────────
  CFAR Mode        0-6         0 (OFF)    Алгоритм CFAR
  Ref Cells        4-64        32         Эталонные ячейки
  Guard Cells      0-8         3          Защитные ячейки
  Threshold        10-100      60         Порог CFAR (6.0 ≈ 1.2 дБ)
  Hybrid α         0-100       50         Вес CA в гибридном режиме
  Hybrid β         0-100       30         Вес GO в гибридном режиме
  Hybrid γ         0-100       20         Вес SO в гибридном режиме
  OS k (%)         50-90       75         k-й порядковый статистик OS
  VI Threshold     5-50        20         Порог индекса вариабельности VI (долго оьяснять, забейте)

Режимы CFAR:

  0 (OFF)    — CFAR отключен, используется фиксированный порог
  1 (CA)     — Cell Averaging — лучший для однородного шума
  2 (GO)     — Greatest Of — устойчив на границах шума
  3 (SO)     — Smallest Of — лучше в засорённых средах
  4 (HYBRID) — Гибридный — взвешенная комбинация CA/GO/SO
  5 (OS)     — Ordered Statistic — лучший для среды с несколькими целями
  6 (VI)     — Variability Index — адаптивное переключение режимов

Рекомендация: по умолчанию OFF (режим 0) — фиксированный порог даёт
максимальную чувствительность. Если эфир многолюдный (дрон + пульт +
соседние VTX одновременно) и фиксированный порог даёт ложные, включите
OS (режим 5) — он наиболее устойчив для обнаружения группы целей.

Порог CFAR:
  Каждая единица ≈ 0,2 дБ. 60 = 6,0 ≈ 1,2 дБ выше шума.
  Увеличивайте для уменьшения ложных, уменьшайте для обнаружения
  слабых сигналов.

Эталонные ячейки:
  Количество ячеек для оценки шума. Больше = точнее оценка, но
  медленнее адаптация. Рекомендуется: 32.

Защитные ячейки:
  Ячейки вокруг тестируемой, исключаемые из оценки шума.
  Рекомендуется: 3. 

(короче берет среднее из соседних)

8. НАСТРОЙКИ ФИЛЬТРА МАХАЛАНОБИСА
================================================================================

Фильтр Махаланобиса отсеивает статистические выбросы, сравнивая текущее
измерение с историей данного дрона.

  Параметр              Диапазон    По умолч.  Описание
  ─────────────────────────────────────────────────────────────────────
  Mahalanobis ON (MG)   ON/OFF     ON         Включение фильтра
  Mahalanobis Thresh    10-100     40         Порог (4.0)

Порог Махаланобиса:
  D² < порог → сигнал принят как валидный дрон.
  40 = 40 — рекомендуется для аналогового FPV (широкий разброс RSSI).
  30 = 30 — более строгий (для цифровых дронов: DJI OcuSync, ELRS).
  10 = 10 — максимально строгий.
  100 = 100 — максимально разрешительный.
(находится над буквами MG)

Как работает:
  1. Собирает историю RSSI и частотной стабильности (8 измерений)
  2. Вычисляет среднее и дисперсию
  3. Рассчитывает расстояние Махаланобиса текущего измерения
  4. Если расстояние выше порога — сигнал отвергается как выброс

между ними. Суммарное время цикла увеличивается пропорционально количеству

10. ОКНА ДЕТЕКЦИИ (SWEEP)
================================================================================

В каждом окне развёртки можно задать до 5 окон детекции (диапазонов
«от … до …», в МГц). Спектр окна при этом всегда рисуется полностью,
а детекция работает только внутри заданных диапазонов.

  Параметр             Диапазон      По умолч.  Описание
  ─────────────────────────────────────────────────────────────────────
  Det Win 1..5 (From)  0-7200 МГц    0          Начало диапазона (МГц)
  Det Win 1..5 (To)    0-7200 МГц    0          Конец диапазона (МГц)

Правила:
  - Если ВСЕ 5 окон = 0 — детекция работает во всём диапазоне окна sweep
    (поведение по умолчанию).
  - Если включено ХОТЯ БЫ ОДНО окно — детекция работает только внутри
    заданных диапазонов, остальные частоты игнорируются.
  - Окно активно, только если заполнены ОБА поля (от и до).
  - Диапазон задаётся в МГц (например 5658.0-5918.0 для FPV-5.8).

Примеры:
  - Смотреть только FPV-5.8 → Det Win 1: From = 5658, To = 5918
  - Комбинация двух полос → Det Win 1: 2400-2483, Det Win 2: 5725-5850
  - Сброс → обнулите все поля From/To (0 = окно выключено)
