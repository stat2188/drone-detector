Enhanced Drone Analyzer (EDA) — Руководство пользователя
Общее описание
EDA — это приложение для обнаружения и анализа беспилотных летательных аппаратов (дронов) на базе HackRF One с прошивкой PortaPack Mayhem. Приложение сканирует радиочастотный спектр, обнаруживает сигналы передатчиков управления и видео, классифицирует их по уровню угрозы и предоставляет визуальную и звуковую индикацию.
Запуск приложения
Включите PortaPack (кнопка питания на корпусе)
В главном меню Mayhem выберите "EDA" (Enhanced Drone Analyzer)
Дождитесь инициализации радиотракта (1–2 секунды)
При первом запуске приложение загружает базу данных частот из файла /FREQMAN/DRONES.TXT. Если файл отсутствует — отобразится предупреждение, но приложение продолжит работу в режиме широкополосного сканирования.

Элементы интерфейса
Table
Элемент	Описание
LNA	Усиление малошумящего усилителя (0–40 дБ)
VGA	Усиление промежуточной частоты (0–62 дБ)
AMP	Включение/выключение усилителя мощности
Vol	Громкость звуковых оповещений (0–99)
Cyc	Количество циклов уменьшения RSSI перед снижением угрозы
Частота	Текущая настроенная частота в МГц
[Md+]	Медианный фильтр (ON/OFF) — подавляет импульсные помехи
Режимы работы
1. Последовательное сканирование (Sequential)
Как включить: Нажмите [Start] при выключенном SWEEP.
Приложение последовательно перебирает частоты из загруженной базы данных. На каждой частоте:
Анализирует спектр 2 МГц полосы
Измеряет RSSI (уровень сигнала)
При обнаружении сигнала выше порога — создаёт запись в списке угроз
Индикация:
Серый — сканирование, нет сигнала
Жёлтый — обнаружен сигнал, анализ (LOCKING)
Зелёный — отслеживание обнаруженного дрона (TRACKING)
Красный — критический уровень сигнала (CRITICAL)
Звуковые сигналы:
Одиночный звуковой сигнал (1000 Гц) — новый дрон обнаружен
SOS-последовательность (1200 Гц) — высокая угроза / приближение
SOS-последовательность (1500 Гц) — критическая угроза
2. Режим развёртки (SWEEP / Looking Glass)
Как включить: Нажмите [Mode] для перехода в режим SWEEP, затем [Start].
В этом режиме приложение быстро «развёртывает» широкий диапазон частот (до 300 МГц и более), отображая спектр в реальном времени. Работает по принципу анализатора спектра с водопадным отображением.
Параметры окон развёртки (настраиваются в [SWP]):
Table
Окно	Диапазон по умолчанию	Назначение
Window 1	5645–5945 МГц	Основной FPV-диапазон 5.8 ГГц
Window 2	2400–2483.5 МГц	Wi-Fi дроны, управление 2.4 ГГц
Window 3	1120–1360 МГц	Дальнобойные FPV-системы 1.2 ГГц
Window 4	433–928 МГц	Управление/телеметрия (433/868/915 МГц)
Важно: Можно включить одно или несколько окон одновременно. Приложение циклически переключается между активными окнами.
Исключения (Exc): В каждом окне можно задать до 5 частот-исключений (например, частоты Wi-Fi точки доступа), которые будут игнорироваться в радиусе ±3 МГц.
3. Автоматический режим (Auto-SWEEP)
Как работает: В sequential режиме приложение автоматически переключается в SWEEP каждые 50 сканов базы данных (DB_SCANS_PER_SWEEP). После завершения цикла развёртки возвращается к сканированию базы.
Это позволяет не пропустить дроны на неизвестных частотах, сохраняя при этом детальное сканирование известных каналов.
Кнопки управления
[Start] / [Stop]
Запускает или останавливает сканирование/развёртку.
[Mode]
Переключение между Sequential и SWEEP режимами:
Sequential → нажать [Mode] → SWEEP
SWEEP → нажать [Mode] → Sequential
[Load]
Загрузка другой базы данных частот:
Нажмите [Load]
Выберите файл .TXT из папки /FREQMAN/
Приложение перезагрузит базу и продолжит сканирование
Формат файла базы данных:
plain
Copy
f=5645000000,d=FPV Raceband CH1
f=5658000000,d=DJI O3
f=2400000000,d=WiFi Drone Control
Первая часть описания (до пробела) определяет тип дрона: FPV, DJI, PARROT, YUNEEC, HOBBY, AUTEL, 3DR, CUSTOM, OTHER.
[Set] — Настройки обнаружения
Открывает экран настроек детекции:
Основные параметры
Table
Параметр	Диапазон	Рекомендация
Int (ms)	10–1000	Интервал сканирования, 50 мс по умолчанию
Sens	0–100	Порог чувствительности (0 = -20 дБм, 100 = -120 дБм)
Vol	0–99	Громкость звука
Cyc	1–50	Циклы до снижения угрозы
Фильтры формы сигнала (Spectrum Shape)

Параметр	Диапазон	Описание
Mar (Margin)	5–200	Минимальный подъём над шумом

MaxW (Max Width)	1–255	Максимальная ширина сигнала
Shrp (Sharpness)	50–250	Крутизна пика (V-образность)

Рекомендации для разных типов сигналов:
Table
Тип сигнала	Margin	MinW	MaxW	Sharpness	Flatness	Valley
FPV аналоговое видео	20	5	200	50	50	0
DJI цифровое (O3/O4)	20	3	40	130	30	80
Wi-Fi / Bluetooth	15	5	255	50	80	0
Узкополосное управление	15	3	20	130	30	80
CFAR — адаптивное обнаружение
Table
Режим	Описание
OFF	Фиксированный порог
CA	Среднее окружение (однородный шум)
GO	Максимум из окон (защита от границ)
SO	Минимум из окон (хорошо для городской среды)
HYBRID	Взвешенная комбинация
OS	Упорядоченная статистика (множественные цели)
VI	Адаптивный выбор по вариативности
Рекомендация: Для городской среды (Wi-Fi, Bluetooth, микроволновки) используйте SO или VI. Для открытого поля — CA или HYBRID.
Дополнительные опции
Dwell — задержка на частоте при обнаружении сигнала
Confirm — требовать подтверждение обнаружения (1–10 раз)
Blklist — чёрный список шумных частот
RVar — отклонение по вариативности RSSI
MG (Mahalanobis Gate) — статистический фильтр выбросов
[SWP] — Настройки развёртки
Открывает экран конфигурации окон SWEEP:
Вкладка 1: Window 1 + Window 2 + исключения
Вкладка 2: Window 3 + Window 4 + исключения
Для каждого окна:
Start (MHz) — начальная частота
End (MHz) — конечная частота
Step (kHz) — шаг перестройки (рекомендуется 1000–20000 кГц)
Enabled — включение окна
Exc (MHz) — частоты-исключения (до 5 штук)
Кнопки:
[DEFAULTS] — сбросить к заводским настройкам
[SAVE] — сохранить в файл на SD-карте
[PTR] — Менеджер паттернов
Открывает экран управления шаблонами сигналов:
Что такое паттерн:
Сохранённый «отпечаток» спектра сигнала (16 точек + характеристики: положение пика, ширина, крутизна). Используется для распознавания типов дронов по форме сигнала.
Опции:
Capture — записать текущий спектр как паттерн
Save — сохранить паттерн на SD-карту
Delete — удалить выбранный паттерн
Live — показать текущий спектр в реальном времени
Режимы сопоставления:
Correlation — корреляционное сравнение (быстро)
Neural — нейросетевой классификатор (если загружен)
Hybrid — комбинация обоих
Символы движения
В списке обнаруженных дронов отображается тренд движения:
Table
Символ	Значение
<	Приближается (RSSI растёт)
>	Удаляется (RSSI падает)
~	Стационарен (RSSI стабилен)
-	Неизвестно (недостаточно данных)
Цветовая индикация угроз
Table
Цвет	Уровень	RSSI	Действие
🟢 Зелёный	LOW	-90…-70 дБм	Обнаружен, далеко
🟡 Жёлтый	MEDIUM	-70…-60 дБм	Средняя угроза
🟠 Оранжевый	HIGH	-60…-40 дБм	Высокая угроза, приближается
🔴 Красный	CRITICAL	> -40 дБм	Критическая угроза, очень близко
Сохранение настроек
Все настройки автоматически сохраняются в файл /EDA/SETTINGS.TXT на SD-карте при нажатии [SAVE] в соответствующем меню.
При следующем запуске приложение загружает сохранённые настройки.
Типичные сценарии использования
Сценарий 1: Поиск неизвестного дрона в городе
Загрузите базу данных с известными FPV-частотами [Load]
В настройках [Set]:
CFAR Mode: SO (устойчив к городскому шуму)
Neighbor Margin: 3 дБ
Confirm Count: 2 (для надёжности)
Нажмите [Start] — последовательное сканирование
При обнаружении сигнала — приложение перейдёт в LOCKING, затем TRACKING
Следите за трендом: < = дрон приближается
Сценарий 2: Мониторинг широкого диапазона (5.8 ГГц FPV)
Нажмите [SWP] — проверьте Window 1: 5645–5945 МГц
Установите Step: 1000 кГц (максимальная детализация)
Добавьте исключения (Exc) для известных помех (например, 5800 МГц — Wi-Fi)
Нажмите [Mode] → [Start]
Наблюдайте спектр в реальном времени
Сценарий 3: Дальнобойный поиск (1.2 ГГц)
[SWP] → Window 3: 1120–1360 МГц, Enabled: ON
Остальные окна: OFF (ускоряет развёртку)
Увеличьте LNA/VGA для максимальной чувствительности
[Mode] → [Start]
