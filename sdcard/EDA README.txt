1. ОБЗОР ПРИЛОЖЕНИЯ
================================================================================

Enhanced Drone Analyzer (EDA) — приложение для обнаружения и анализа
беспилотных летательных аппаратов (БПЛА) на базе HackRF One с прошивкой
PortaPack Mayhem.

Основные возможности:
  - Сканирование радиочастотного спектра от 1 МГц до 7,2 ГГц
  - Режим развёртки (SWEEP) — до 300 МГц за цикл
  - Отслеживание дронов в реальном времени с классификацией угроз
  - 7 алгоритмов CFAR-детектирования
  - Фильтр Махаланобиса для отсеивания статистических выбросов
  - Анализ формы спектра (V-образная форма, глубина впадины, симметрия)
  - Автоматическое управление усилением радиотракта (AGC)
  - Звуковые оповещения с SOS-последовательностью для критических угроз
  - Сопоставление с эталонными паттернами (RF fingerprinting)
  - Сохранение настроек на SD-карту

Целевая платформа:
  - МК: STM32F405RG (ARM Cortex-M4F, 168 МГц)
  - ОЗУ: 128 КБ SRAM (~64 КБ доступно для приложения)
  - Flash: 1 МБ
  - ОС: ChibiOS (кооперативные + превентивные потоки)
  - Дисплей: 240×320 пикселей, 16 бит RGB565
  - RF: HackRF One (Si5351, MAX2837, RFFC5072)

2. ЗАПУСК И ОСНОВНОЙ ЭКРАН
================================================================================

Запуск:
  1. Включите PortaPack (кнопка питания на корпусе)
  2. В главном меню Mayhem выберите "EDA" (Enhanced Drone Analyzer)
  3. Дождитесь инициализации радиотракта (1-2 секунды)

При первом запуске приложение загружает базу данных частот из файла
/FREQMAN/DRONES.TXT. Если файл отсутствует — отобразится предупреждение,
но приложение продолжит работу в режиме широкополосного сканирования.

Элементы интерфейса:
  LNA      — Усиление малошумящего усилителя (0-40 дБ, шаг 8 дБ)

  [Md+]    — Медианный фильтр (ON/OFF) — подавляет импульсные помехи

3. РЕЖИМЫ РАБОТЫ
================================================================================

3.1 Последовательное сканирование (Sequential)
-----------------------------------------------
Как включить: Нажмите [Start] при выключенном SWEEP.

Приложение последовательно перебирает частоты из загруженной базы данных.
На каждой частоте:
  - Анализирует спектр 2 МГц полосы
  - Измеряет RSSI (уровень сигнала)
  - При обнаружении сигнала выше порога — создаёт запись в списке угроз

Индикация:
  Серый    — сканирование, нет сигнала
  Жёлтый   — обнаружен сигнал, анализ (LOCKING)
  Зелёный  — отслеживание обнаруженного дрона (TRACKING)
  Красный  — критический уровень сигнала (CRITICAL)

Звуковые сигналы:
  Одиночный звук (1000 Гц) — новый дрон обнаружен
  SOS (1200 Гц) — высокая угроза / приближение
  SOS (1500 Гц) — критическая угроза

3.2 Режим развёртки (SWEEP / Looking Glass)
---------------------------------------------
Как включить: Нажмите [Mode] для перехода в режим SWEEP, затем [Start].

Режим быстро «развёртывает» любой диапазон частот от 1 до 7.200 mhz,
отображая спектр в реальном времени. Работает как анализатор спектра с
водопадным отображением.

Параметры окон развёртки (настраиваются в [SWP]):
  Окно 1: 5645-5945 МГц  — Основной FPV-диапазон 5.8 ГГц
  Окно 2: 2400-2483.5 МГц — Wi-Fi дроны, управление 2.4 ГГц
  Окно 3: 1120-1360 МГц  — Дальнобойные FPV-системы 1.2 ГГц
  Окно 4: 433-928 МГц    — Управление/телеметрия (433/868/915 МГц)

Важно: Можно включить одно или несколько окон одновременно. Приложение
циклически переключается между активными окнами.

Исключения (Exc): В каждом окне можно задать до 5 частот-исключений
(например, частоты Wi-Fi точки доступа), которые будут игнорироваться
в радиусе ±3 МГц.

3.3 Автоматический режим (Auto-SWEEP)
---------------------------------------
Как работает: В sequential режиме приложение автоматически переключается
в SWEEP каждые 50 сканов базы данных (DB_SCANS_PER_SWEEP). После
завершения цикла развёртки возвращается к сканированию базы.

Это позволяет не пропустить дроны на неизвестных частотах, сохраняя
при этом детальное сканирование известных каналов.

================================================================================
4. УПРАВЛЕНИЕ СКАНИРОВАНИЕМ
================================================================================

[Start] / [Stop]
  Запускает или останавливает сканирование/развёртку.

[Mode]
  Переключение между Sequential и SWEEP режимами:
  Sequential → нажать [Mode] → SWEEP
  SWEEP → нажать [Mode] → Sequential

[Load]
  Загрузка другой базы данных частот:
  1. Нажмите [Load]
  2. Выберите файл .TXT из папки /FREQMAN/
  3. Приложение перезагрузит базу и продолжит сканирование

  Формат файла базы данных:
    f=5645000000,d=FPV Raceband CH1
    f=5658000000,d=DJI O3
    f=2400000000,d=WiFi Drone Control

  Первая часть описания (до пробела) определяет тип дрона:
    FPV, DJI, PARROT, YUNEEC, HOBBY, AUTEL, 3DR, CUSTOM, OTHER

[Set] — Настройки обнаружения
  Открывает экран настроек детекции (см. раздел 5).

[SWP] — Настройки развёртки
  Открывает настройки окон развёртки (см. раздел 9).

[PTR] — Управление паттернами
  Открывает менеджер паттернов RF-отпечатков (см. раздел 12).

5. НАСТРОЙКИ ОБНАРУЖЕНИЯ (ЭКРАН [Set])
================================================================================

Экран настроек содержит все параметры обнаружения, разделённые на группы.

5.1 Основные параметры
------------------------
  Параметр     Диапазон    По умолч.  Описание
  ─────────────────────────────────────────────────────────────────────
  Int (ms)     10-1000     50         Интервал сканирования базы данных (мс)
  Sens         0-100       50         Порог чувствительности по умолчанию 75
  Low (dBm)    -120..-80   -95        Порог угрозы LOW
  Med (dBm)    -120..-80   -89        Порог угрозы MEDIUM
  High (dBm)   -120..-80   -85        Порог угрозы HIGH
  Crit (dBm)   -120..-80   -82        Порог угрозы CRITICAL
  Dwell        ON/OFF      OFF        Задержка на частоте (для подтверждения)
  Conf ON      ON/OFF      ON         Подтверждение обнаружения
  Conf N       1-10        2          Количество подтверждений из базы данных на частоте
  Miss T       1-20        6          Пропусков до потери захвата
  Neighbor     0-15 дБ     2          Маргин соседних бинов (дБ) (сканирование по базе данных)
  RSSI Var     ON/OFF      OFF        Фильтр дисперсии RSSI (база данных)
  Noise BL     ON/OFF      OFF        Чёрный список шумовых частот (база данных)
  Spectr Det   ON/OFF      ON         Детектирование по спектру
  Md+          ON/OFF      OFF        Медианный фильтр
  Sensitive    ON/OFF      OFF        Чувствительный режим (расслабляет фильтры без лишних манипуляций)
  Bypass       ON/OFF      OFF        Обход фильтров формы (SWEEP режим любой мощный сигнал близко мимо фильтров)
  Freq Match   0-100 МГц   1          Радиус совпадения частот (МГц) (слияние близких частот в одну запись в режиме SWEEP, так как у FPV много каналов, так же чтобы не создавать слишком ного записей в памяти) Записи сливаются в последнюю сохраняя RSSI наиболее сильной.

5.2 Пояснения к основным параметрам
-------------------------------------

Int (ms) — Интервал сканирования
  Определяет, как часто приложение переключает частоту и анализирует
  спектр. Меньшие значения = быстрее сканирование, но менее стабильные
  измерения. Рекомендуется: 50 мс (20 частот/сек).

Sens — Порог чувствительности
  Управляет порогом обнаружения сигнала. Значение 0 = -20 дБм (очень
  строгий), 100 = -120 дБм (максимально чувствительный).
  Рекомендуется: 50 (-95 дБм) для FPV-дронов.

Low/Med/High/Crit — Пороги угроз
  Определяют границы между уровнями угроз:
    LOW:    -95 дБм (слабый, но обнаруженный сигнал)
    MEDIUM: -89 дБм (умеренный сигнал)
    HIGH:   -85 дБм (сильный сигнал)
    CRITICAL: -82 дБм (очень сильный, близкое расстояние)

  Важно: MEDIUM должен быть как минимум на 3 дБ выше порога обнаружения
  (Low), иначе полоса LOW будет недостижима.

Dwell — Задержка на частоте
  При включении приложение задерживается на каждой частоте на несколько
  циклов для подтверждения наличия сигнала. Уменьшает ложные срабатывания,
  но замедляет сканирование.

Conf N — Количество подтверждений
  Сколько раз подряд необходимо обнаружить сигнал, чтобы создать запись
  о дроне. Больше = меньше ложных, но медленнее обнаружение.

Miss T — Пропусков до потери захвата
  Сколько циклов подряд можно пропустить сигнал, прежде чем запись о
  дроне будет удалена. Увеличивайте для нестабильных аналоговых FPV-сигналов.

Neighbor — Маргин соседних бинов
  Центральный бин сигнала должен превышать соседние бины на это значение.
  0 = отключено, 2 = рекомендуется для FPV (широкий сигнал), 5 = строго.

RSSI Var — Фильтр дисперсии RSSI
  Отсеивает шумовые сигналы с хаотическими колебаниями уровня.
  Реальные дроны: дисперсия < 25. Шум: > 100.

Noise BL — Чёрный список шумовых частот
  Если сканер обнаруживает шум на частоте 3+ раза без повышения угрозы,
  частота временно пропускается.

Spectr Det — Детектирование по спектру
  Использует анализ формы спектра для определения наличия сигнала.
  Отключите, если нужно только измерение RSSI.

Md+ — Медианный фильтр
  Подавляет импульсные помехи (микроволновка, Bluetooth). Полезен в
  городских условиях, но может замедлить обнаружение коротких импульсов.

Sensitive — Чувствительный режим
  Ослабляет фильтры формы спектра для обнаружения слабых/дальних
  сигналов. Может увеличить количество ложных срабатываний.

Bypass — Обход фильтров формы
  При включении пропускает проверку глубины впадины, симметрии и
  эксцесса для очень сильных сигналов (>80 единиц над шумом).
  По умолчанию ВЫКЛ — фильтры формы работают всегда.

Freq Match — Радиус совпадения частот
  Определяет, насколько близкие по частоте сигналы считаются одним
  дроном. 1 МГц = рекомендуется (FPV-каналы ≥5 МГц).
  0 = только точные совпадения (нет слияния).

6. НАСТРОЙКИ ФОРМЫ СПЕКТРА
================================================================================

Фильтры формы спектра определяют характерный «отпечаток» сигнала дрона
(V-образная форма) и отсеивают помехи (WiFi, Bluetooth, микроволновки).

  Параметр         Диапазон    По умолч.  Описание
  ─────────────────────────────────────────────────────────────────────
  Margin           5-200       5          Маргина шума (5 = ~1 дБ)
  Min Width        1-100       2          Мин. ширина сигнала (бины)
  Max Width        1-255       230        Макс. ширина сигнала (бины)
  Sharpness        50-250      75         Острота пика (отношение пик/среднее)
  Peak Ratio       0-255       0          Отношение пик/ширина (0=отключено) хз как это работает. Потом разберусь.
  Valley Depth     0-200       80         Глубина впадины (0=отключено)
  Flatness         0-100       35         Плосковершинность (% бинов >90% пика)
  Symmetry         0-100       0          Симметрия (0=отключено)

Пояснения:

Margin — Маргина шума
  Минимальное превышение пика над уровнем шума. 5 единиц ≈ 1 дБ.
  Увеличивайте для строгой фильтрации, уменьшайте для обнаружения
  слабых сигналов.

Min Width — Минимальная ширина
  Сигналы уже этого порога отбрасываются как игольчатые всплески.
  2 бина = 156 кГц — ловит узкие командные посылки (ELRS, FrSky).

Max Width — Максимальная ширина
  Сигналы шире этого порога отбрасываются как плосковершинный шум.
  230 бинов = ~18 МГц — пропускает FPV-видео.

Sharpness — Острота пика
  Отношение маргина пика к среднему маргину. V-образные пики >200,
  плоские WiFi/BT ≈100. 75 = рекомендуется для FPV.

Peak Ratio — Отношение пик/ширина
  Пик делится на ширину сигнала. 0 = отключено (рекомендуется для FPV,
  так как широкий FPV-сигнал имеет низкое соотношение).

Valley Depth — Глубина впадины
  Измеряет маргин бинов, примыкающих к пику. V-образный сигнал имеет
  глубокие впадины, WiFi/BT — мелкие. 80 = рекомендуется.

Flatness — Плосковершинность
  Процент бинов с мощностью >90% от пика. WiFi/BT: 50-80%,
  drone V-shape: 5-20%. 35 = рекомендуется.

Symmetry — Симметрия
  Отношение меньшей ширины к большей (в процентах). 0 = отключено
  (рекомендуется, так как аналоговый FPV часто имеет легкую
  асимметрию из-за дрейфа модулятора).

Важно: При очень сильных сигналах (>80 единиц над шумом) автоматически
ослабляются проверки глубины впадины и симметрии, так как на близком
расстоянии все бины в полосе сигнала оказываются повышенными.

7. НАСТРОЙКИ CFAR-ДЕТЕКТИРОВАНИЯ
================================================================================

CFAR (Constant False Alarm Rate) — адаптивный порог, подстраивающийся
под уровень шума. Уменьшает ложные срабатывания в различных условиях.

  Параметр         Диапазон    По умолч.  Описание
  ─────────────────────────────────────────────────────────────────────
  CFAR Mode        0-6         5 (OS)     Алгоритм CFAR
  Ref Cells        4-64        32         Эталонные ячейки
  Guard Cells      0-8         3          Защитные ячейки
  Threshold        10-100      60         Порог CFAR (6.0 ≈ 1.2 дБ)
  Hybrid α         0-100       50         Вес CA в гибридном режиме
  Hybrid β         0-100       30         Вес GO в гибридном режиме
  Hybrid γ         0-100       20         Вес SO в гибридном режиме
  OS k (%)         50-90       75         k-й порядковый статистик OS
  VI Threshold     5-50        20         Порог индекса вариабельности VI (долго оьяснять, забейте)

Режимы CFAR:

  0 (OFF)    — CFAR отключен, используется фиксированный порог
  1 (CA)     — Cell Averaging — лучший для однородного шума
  2 (GO)     — Greatest Of — устойчив на границах шума
  3 (SO)     — Smallest Of — лучше в засорённых средах
  4 (HYBRID) — Гибридный — взвешенная комбинация CA/GO/SO
  5 (OS)     — Ordered Statistic — лучший для среды с несколькими целями
  6 (VI)     — Variability Index — адаптивное переключение режимов

Рекомендация: OS (режим 5) — наиболее устойчив для обнаружения группы
дронов или дрона + пульта управления одновременно.

Порог CFAR:
  Каждая единица ≈ 0,2 дБ. 60 = 6,0 ≈ 1,2 дБ выше шума.
  Увеличивайте для уменьшения ложных, уменьшайте для обнаружения
  слабых сигналов.

Эталонные ячейки:
  Количество ячеек для оценки шума. Больше = точнее оценка, но
  медленнее адаптация. Рекомендуется: 32.

Защитные ячейки:
  Ячейки вокруг тестируемой, исключаемые из оценки шума.
  Рекомендуется: 3. 

(короче берет среднее из соседних)

8. НАСТРОЙКИ ФИЛЬТРА МАХАЛАНОБИСА
================================================================================

Фильтр Махаланобиса отсеивает статистические выбросы, сравнивая текущее
измерение с историей данного дрона.

  Параметр              Диапазон    По умолч.  Описание
  ─────────────────────────────────────────────────────────────────────
  Mahalanobis ON        ON/OFF     ON         Включение фильтра
  Mahalanobis Thresh    10-100     40         Порог (4.0)

Порог Махаланобиса:
  D² < порог → сигнал принят как валидный дрон.
  40 = 40 — рекомендуется для аналогового FPV (широкий разброс RSSI).
  30 = 30 — более строгий (для цифровых дронов: DJI OcuSync, ELRS).
  10 = 10 — максимально строгий.
  100 = 100 — максимально разрешительный.
(находится над буквами MG)

Как работает:
  1. Собирает историю RSSI и частотной стабильности (8 измерений)
  2. Вычисляет среднее и дисперсию
  3. Рассчитывает расстояние Махаланобиса текущего измерения
  4. Если расстояние выше порога — сигнал отвергается как выброс

9. НАСТРОЙКИ РАЗВЁРТКИ (SWEEP)
================================================================================

Настройки окон развёртки доступны через кнопку [SWP].

9.1 Окна развёртки
--------------------
Каждое окно настраивается independently:

  Параметр       Значение по умолчанию
  ─────────────────────────────────────────────
  Start          5645 МГц (окно 1)
  End            5945 МГц (окно 1)
  Step           8.8 МГц (автоматически)
  Enabled        ON/OFF

Окно 1 (5.8 ГГц FPV):
  Start: 5645 МГц — Начало полного диапазона FPV
  End:   5945 МГц — Конец полного диапазона FPV
  Step:  8.8 МГц — Максимальный шаг без «слепых зон»

Окно 2 (2.4 ГГц WiFi/управление):
  Start: 2400 МГц
  End:   2483.5 МГц
  Step:  8.8 МГц

Окно 3 (1.2 ГГц дальнобойные FPV):
  Start: 1120 МГц
  End:   1360 МГц
  Step:  8.8 МГц

Окно 4 (433/868/915 МГц управление):
  Start: 433 МГц
  End:   928 МГц
  Step:  8.8 МГц

Важно: При включении нескольких окон приложение циклически переключается
между ними. Суммарное время цикла увеличивается пропорционально количеству
активных окон.

9.2 Параметры развёртки
-------------------------
  SWEEP_PERSISTENCE_DECAY  = 224/256 (0.875) — скорость затухания
  SWEEP_NOISE_FLOOR        = 15 процентиль — порог шума для отображения
  SWEEP_DISPLAY_NOISE_MARGIN = 8 — дополнительный порог шума
  SWEEP_FFT_TRIGGER        = 63 — накопление FFT для чувствительности
(HARDCODED. Это вам не нужно)

10. ИСКЛЮЧЕНИЯ ЧАСТОТ
================================================================================

В каждом окне развёртки можно задать до 5 частот-исключений.
Исключённые частоты игнорируются в радиусе ±Radius МГц.

  Параметр            Диапазон    По умолч.  Описание
  ─────────────────────────────────────────────────────────────────────
  Exception 1-5       Частота     0          Частота исключения (Гц)
  Exception Radius    1-100 МГц   3          Радиус исключения (МГц)

Примеры:
  - Wi-Fi точка доступа на 2412 МГц → Exception = 2412000000
  - Базовая станция DJI на 5745 МГц → Exception = 5745000000
  - Радиолюбительский пеленгатор на 433 МГц → Exception = 433000000

Радиус исключения:
  какой хотите. Сделает слепую дыру на спектре

11. ЗВУКОВЫЕ ОПОВЕЩЕНИЯ
================================================================================

Настройки звука:

  Параметр       Диапазон    По умолч.  Описание
  ─────────────────────────────────────────────────────────────────────
  Audio          ON/OFF      ON         Включение звука
  Vol            0-99        50         Громкость

Типы звуковых сигналов:

  Событие                          Частота    Длительность
  ─────────────────────────────────────────────────────────────
  Новый дрон обнаружен             1000 Гц    150 мс
  Угроза повышена                  1000 Гц    100 мс
  Дрон приближается                1200 Гц    200 мс (SOS)
  Высокая угроза                   1200 Гц    200 мс (SOS)
  Критическая угроза               1500 Гц    200 мс (SOS)
  Дрон отдаляется                  800 Гц     150 мс (потом может будет)

Последовательность SOS:
  • • • — — — • • • (три коротких, три длинных, три коротких)

Важно: Звуковые сигналы могут кратковременно прерываться во время обновления
интерфейса (блокирующая запись DAC).

12. УПРАВЛЕНИЕ ПАТТЕРНАМИ (RF FINGERPRINTS) (ПОКА НЕ РАБОТАЕТ)
================================================================================

Менеджер паттернов ([PTR]) позволяет создавать и загружать эталонные
RF-отпечатки для улучшения идентификации дронов.

Формат паттерна (CSV):
  name,wave[16],features[4],threshold,flags,center_freq,range_width

  name          — Имя паттерна (например, "DJI_Mavic_3")
  wave[16]      — 16-элементный массив амплитудного профиля
  features[4]   — 4 признака формы спектра
  threshold     — Порог совпадения
  flags         — Флаги (тип дрона и т.д.)
  center_freq   — Центральная частота (Гц)
  range_width   — Ширина диапазона (Гц)

Хранение:
  Паттерны хранятся в /EDA/PATTERNS/*.TXT на SD-карте.

Создание паттерна:
  1. Обнаружите целевой дрон в EDA
  2. Сохраните его RF-отпечаток через менеджер паттернов
  3. Отредактируйте файл на компьютере при необходимости

Использование:
  При обнаружении сигнала EDA сравнивает его с загруженными паттернами
  используя SAD (Sum of Absolute Differences). Если совпадение выше
  порога — дрон идентифицируется по типу.

================================================================================
13. ФАЙЛЫ НА SD-КАРТЕ
================================================================================

Структура каталогов:

/FREQMAN/
  DRONES.TXT           — База данных частот дронов (по умолчанию)
  *.TXT                — Пользовательские файлы freqman

/EDA/
  SETTINGS.TXT         — Настройки EDA (все параметры)
  PATTERNS/
    *.TXT              — Паттерны RF-отпечатков (CSV)
    DJI_Mavic.TXT      — Пример паттерна
    FPV_Analog.TXT     — Пример паттерна

ФорматSETTINGS.TXT:
  Версия: 1
  Формат: Ключ=Значение (по одному на строку)
  Ключи соответствуют именам полей SettingsStruct

  Пример:
    scanning_mode=0
    scan_interval_ms=50
    scan_sensitivity=50
    threat_low_dbm=-95
    threat_medium_dbm=-89
    threat_high_dbm=-85
    threat_critical_dbm=-82
    audio_alerts_enabled=1
    volume=50
    cfar_mode=5
    cfar_ref_cells=32
    cfar_guard_cells=3
    cfar_threshold_x10=60
    mahalanobis_enabled=1
    mahalanobis_threshold_x10=40
    sweep_start_freq=5645000000
    sweep_end_freq=5945000000

Формат базы данных (DRONES.TXT):
  Формат freqman: f=частота,d=описание
  Или CSV: частота,описание

  Пример:
    f=5645000000,d=FPV Raceband CH1
    f=5658000000,d=DJI O3
    f=2400000000,d=WiFi Drone Control

Формат паттернов (PATTERNS/*.TXT):
  CSV: name,wave[16],features[4],threshold,flags,center_freq,range_width
  25 полей (новый формат), 29 полей (старый формат, поддерживается)

================================================================================
14. ЦВЕТА И ИНДИКАЦИЯ
================================================================================

Цвета угроз (RGBA):
  Зелёный   (#00FF00) — LOW (низкая угроза)
  Жёлтый    (#FFFF00) — MEDIUM (средняя угроза)
  Оранжевый (#FF8000) — HIGH (высокая угроза)
  Красный   (#FF0000) — CRITICAL (критическая угроза)
  Серый     (#808080) — Unknown (неизвестный тип)

Символы тренда:
  < — Дрон приближается
  > — Дрон отдаляется
  ~ — Дрон статичен
  — — Тренд неизвестен

Индикация статуса:
  Scan (N)   — Сканирование, N обработанных частот
  Sweep      — Режим развёртки активен
  Locked     — Захвачен сигнал дрона
  Tracking   — Отслеживание дрона

15. ПОЛНАЯ ТАБЛИЦА НАСТРОЕК
================================================================================

Все параметры, доступные в SettingsStruct:

Группа: Сканирование
  scanning_mode            — Режим сканирования (0=Sequential)
  scan_interval_ms         — Интервал сканирования (мс, 50)
  scan_sensitivity         — Чувствительность (0-100, 50)
  alert_rssi_threshold_dbm — Порог RSSI для оповещения (дБм)
  threat_low_dbm           — Порог LOW (дБм, -95)
  threat_medium_dbm        — Порог MEDIUM (дБм, -89)
  threat_high_dbm          — Порог HIGH (дБм, -85)
  threat_critical_dbm      — Порог CRITICAL (дБм, -82)

Группа: Отображение
  spectrum_visible         — Видимость спектра (ON/OFF)
  timeline_visible         — Видимость таймлайна (ON/OFF)

Группа: Оповещения
  audio_alerts_enabled     — Звуковые оповещения (ON/OFF)
  volume                   — Громкость (0-99, 50)

Группа: Признаки обнаружения
  dwell_enabled            — Задержка на частоте (ON/OFF)
  confirm_count_enabled    — Подтверждение обнаружения (ON/OFF)
  noise_blacklist_enabled  — Чёрный список шума (ON/OFF)
  spectrum_detection_enabled — Детектирование по спектру (ON/OFF)
  median_enabled           — Медианный фильтр (ON/OFF)

Группа: Форма спектра
  spectrum_margin          — Маргина шума (5-200, 5)
  spectrum_min_width       — Мин. ширина (1-100, 2)
  spectrum_max_width       — Макс. ширина (1-255, 230)
  spectrum_peak_sharpness  — Острота пика (50-250, 75)
  spectrum_peak_ratio      — Отношение пик/ширина (0-255, 0)
  spectrum_valley_depth    — Глубина впадины (0-200, 80)
  spectrum_flatness        — Плосковершинность (0-100, 35)
  spectrum_symmetry        — Симметрия (0-100, 0)

Группа: CFAR
  cfar_mode                — Режим CFAR (0-6, 5=OS)
  cfar_ref_cells           — Эталонные ячейки (4-64, 32)
  cfar_guard_cells         — Защитные ячейки (0-8, 3)
  cfar_threshold_x10       — Порог CFAR (10-100, 60)
  cfar_hybrid_alpha        — Вес CA гибрида (0-100, 50)
  cfar_hybrid_beta         — Вес GO гибрида (0-100, 30)
  cfar_hybrid_gamma        — Вес SO гибрида (0-100, 20)
  os_cfar_k_percent        — k-й порядковый OS (50-90%, 75)
  vi_cfar_threshold_x10    — Порог VI (5-50, 20)

Группа: Анти-ложные
  neighbor_margin_db       — Маргин соседей (дБ, 0-15, 2)
  rssi_variance_enabled    — Фильтр дисперсии RSSI (ON/OFF)
  confirm_count            — Подтверждений (1-10, 2)
  miss_tolerance           — Пропусков до потери (1-20, 6)

Группа: Махаланобис
  mahalanobis_enabled      — Фильтр Махаланобиса (ON/OFF)
  mahalanobis_threshold_x10 — Порог (10-100, 40)

Группа: Чувствительность
  sensitive_mode           — Чувствительный режим (ON/OFF)
  shape_bypass_enabled     — Обход фильтров формы (ON/OFF)
  kurtosis_enabled         — Эксцесс (ON/OFF, только файл)
  kurtosis_min_x10         — Мин. эксцесс (×10, 20)
  adaptive_cfar_enabled    — Адаптивный CFAR (ON/OFF, только файл)

Группа: Развёртка (окно 1)
  sweep_start_freq         — Нач. частота (Гц)
  sweep_end_freq           — Кон. частота (Гц)

Группа: Развёртка (окно 2)
  sweep2_start_freq        — Нач. частота (Гц)
  sweep2_end_freq          — Кон. частота (Гц)
  sweep2_step_freq         — Шаг частоты (Гц)
  sweep2_enabled           — Включение окна 2 (ON/OFF)

Группа: Развёртка (окно 3)
  sweep3_start_freq        — Нач. частота (Гц)
  sweep3_end_freq          — Кон. частота (Гц)
  sweep3_step_freq         — Шаг частоты (Гц)
  sweep3_enabled           — Включение окна 3 (ON/OFF)

Группа: Развёртка (окно 4)
  sweep4_start_freq        — Нач. частота (Гц)
  sweep4_end_freq          — Кон. частота (Гц)
  sweep4_step_freq         — Шаг частоты (Гц)
